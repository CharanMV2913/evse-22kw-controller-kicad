# 22 kW EVSE controller project

The repository now contains the prototype implementation specification, safety-state-machine guidance, release checklist, and initial KiCad board outline.

This is an engineering prototype baseline, not a certified charger. The next mandatory step is exact component selection and schematic capture against the chosen external Type A + RDC-DD or Type B protection assembly. The board must remain SELV/control-only; do not add 415 V conductors to it.

See `docs/implementation-spec.md` and `docs/release-checklist.md` before ordering boards.
